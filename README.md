Not much to say, this is the repo for my site. This is a remake of the site with Nuxt.js.

## Building

1. Download all the necessary packages with:

```sh
bun install
```

2. The site can be previewed live with:

```sh
bun run dev
```

3. Building the site statically is done with:

```sh
bun run generate
```

The output is placed in `.output/public`.
